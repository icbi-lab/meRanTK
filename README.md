# meRanTK 1.x (Perl)

> **meRanTK 2 (Python rewrite, new features) is developed at
> [github.com/icbi-lab/meRanTK2](https://github.com/icbi-lab/meRanTK2).**
> This repository contains the Perl version 1.x, kept for reproducibility. New
> development happens in meRanTK 2.

methylated RNA analysis Tool Kit — tools for the detection of m5C from RNA
bisulfite sequencing (RNA-BSseq) data: meRanGs/meRanGh (genome alignment,
STAR/HISAT2), meRanT (transcriptome alignment, Bowtie2), meRanCall,
meRanCompare, meRanAnnotate.

© Dietmar Rieder, 2022

See [README](README) for installation and usage, and the
[manual](http://icbi.at/software/meRanTK/downloads/1.3.0/meRanTK_userGuide.pdf).
